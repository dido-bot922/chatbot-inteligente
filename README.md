# 🤖 ChatBot Inteligente

Um chatbot web inteligente que conversa com você sobre tecnologia, programação e muito mais!

## ✨ Características

- 💬 **Interface amigável** - Design moderno e responsivo
- 🧠 **Base de conhecimento** - Sabe sobre tecnologia, programação, dicas úteis e muito mais
- ⚡ **Rápido e leve** - Roda 100% no navegador, sem dependências pesadas
- 📱 **Responsivo** - Funciona perfeitamente em celular, tablet e desktop
- 🎨 **Bonito** - Com gradientes modernos e animações suaves

## 🚀 Como Usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/dido-bot922/chatbot-inteligente.git
   cd chatbot-inteligente
   ```

2. Abra o arquivo `index.html` no seu navegador (ou use um servidor local)

3. Comece a conversar com o chatbot! 😊

## 📚 Tópicos que o ChatBot Conhece

- **Tecnologia**: JavaScript, HTML, CSS, Python, React, APIs, Git, GitHub
- **Dicas de Programação**: Como aprender, como fazer um site
- **Motivação**: Quando está cansado ou desanimado
- **Saudações**: Olá, oi, opa, tudo bem?
- **E muito mais!**

## 📁 Estrutura do Projeto

```
chatbot-inteligente/
├── index.html      # Interface do chatbot
├── style.css       # Estilos e design
├── script.js       # Lógica e base de conhecimento
└── README.md       # Este arquivo
```

## 🛠️ Como Expandir

Para adicionar mais respostas ao chatbot, edite o objeto `knowledgeBase` no arquivo `script.js`:

```javascript
const knowledgeBase = {
    'sua-pergunta': 'Sua resposta aqui',
    'outra-pergunta': 'Outra resposta',
    // ... mais entradas
};
```
